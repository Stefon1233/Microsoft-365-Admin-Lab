# Ticket ##
Ticket 010 — New Employee Onboarding

### Issue

New employee requires a fully configured Microsoft 365 account.

### User Report

Management requested Microsoft 365 access for a newly hired employee.

### Environment

* Microsoft 365 Admin Center
* Microsoft Entra ID
* Microsoft Teams
* Microsoft 365 Groups

### Symptoms

New employee does not yet have:

* Microsoft 365 account
* License
* Department information
* Team/group membership
* Initial credentials

### Investigation

Reviewed the onboarding requirements and determined which license, department, job title, and Microsoft 365 group/Team the employee required.

### Troubleshooting Steps

1. Created a new fictional employee account.
2. Configured the user's display name and username.
3. Set the employee's department.
4. Added the appropriate job title.
5. Assigned the required Microsoft 365 license.
6. Added the employee to the appropriate Microsoft 365 Team/group.
7. Generated/set a temporary password.
8. Required the employee to change the password during first sign-in.
9. Reviewed the completed account configuration.
10. Signed in using the new employee account.
11. Changed the temporary password when prompted.
12. Verified Microsoft 365 access.
13. Verified Team/group membership.
14. Confirmed onboarding was complete.

### Resolution

The new employee account was successfully created, licensed, configured, and added to the required Microsoft 365 resources.

### Root Cause

Normal new-hire onboarding request.
