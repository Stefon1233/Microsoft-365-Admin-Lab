# Ticket ##
Ticket 007 — OneDrive Deleted File

### Issue

User accidentally deleted a OneDrive file.

### User Report

User reported that an important file was missing after accidental deletion.

### Environment

* Microsoft OneDrive
* Microsoft 365

### Symptoms

* File no longer appears in its original OneDrive folder.
* User needs the file recovered.

### Investigation

* Confirmed the file was missing from its original location.
* Checked the OneDrive Recycle Bin.
* Located the deleted file.

### Troubleshooting Steps

1. Created/selected a test file.
2. Deleted the file.
3. Verified that it disappeared from its original folder.
4. Opened the OneDrive **Recycle Bin**.
5. Located the deleted file.
6. Selected **Restore**.
7. Returned to the original folder.
8. Verified that the file had been recovered.

### Resolution

The deleted file was successfully restored from the OneDrive Recycle Bin.

### Root Cause

Accidental user deletion.

* OneDrive
* File Recovery
* Microsoft 365
* End-User Support
* Data Recovery
